## A. 核心诉求：品牌图标 + 涂鸦质感

- [ ] **A1 技能方块换品牌图标**
  - [ ] 用 simple-icons 官方 SVG：Word / Excel / PowerPoint / Canva / ChatGPT / DeepSeek / 剪映(CapCut) / 飞书(Lark)，存放 `public/skills/`
  - [ ] 方块样式改为「图标 + 品牌色」，去掉手绘缩写字母
  - [ ] ⚠️ 依赖：**OpenClaw、即梦** 无现成品牌图，需本人提供图片
- [ ] **A2 涂鸦风背景体系**
  - [x] **A2b 马克笔笔触高亮**（优先，效果最出感觉）：`mark` 高亮从规整矩形改成歪扭笔触（不规则 clip-path 或 SVG 笔刷背景），保留换行贴合（box-decoration-break）✅ 2026-11-24 完成，采用加强版（斜收笔+毛边+墨色不均），笔刷 SVG 见 `src/assets/brush-*.svg`
  - [ ] **A2a 卡片手绘质感**：白卡片加纸纹（SVG 噪点纹理）、手绘歪边框（feTurbulence 抖边或手绘描边 SVG）、四角和纸胶带
  - [ ] 区块底纹点缀涂鸦小元素

## B. 布局与呼吸感

- [ ] **B1 左右列高度失衡**：左列约 1400px、右列 1200px 后空白 → 「校园经历」挪右列，或数据亮点便签下移填空
- [ ] **B2 贴纸排布**：6 个贴纸现为均匀网格 → 改叠压 + 旋转错落，空隙加 doodle（箭头/星星/圈）
- [ ] **B3 时间线**：虚线改手绘抖线 SVG path，节点圆点大小不一
- [ ] **B4 页脚**：手绘胶带压角 + 签名式收尾小字

## C. 照片与头部

- [ ] **C1 照片去底贴纸化**：抠出人像（透明底）+ 白色描边贴纸，叠在黄色块上（参考图灵魂）

- [ ] **D3 悬停微动效**：贴纸 hover 轻旋转/放大、胶带翘角（纯 CSS transform，不影响打印）
